0.1.130's biome named the oceans it replaces as `deep_ocean` and `deep_cold_ocean`; the game wants `minecraft:deep_ocean` and `minecraft:deep_cold_ocean`, so it threw the whole biome away (content log: "No biome found with name: 'deep_ocean'") and no Deep Trench was made.
